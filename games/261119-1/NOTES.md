# ふぉーん！ママのドレッサーでおでかけじゅんび

- **起動**: `index.html` をそのまま開く（単一ファイル・外部読み込みなし。file:// でも Pages の下位フォルダでも動く）。作り直すときは `python3 build.py`（`src/*.js` と `vendor/three.min.js` を1枚にまとめるだけ）。
- **流れ**: 三面鏡を開く → タオルを引く → ドライヤーで乾かす（ふわふわ爆発） → ブラシでとかす（寝ぐせが1本ぴょこん） → オルゴール箱を開ける → クリップで寝ぐせを留める → ポシェットを掛ける → 玄関のドアを開ける → 日傘のママと手をつないでお出かけ → 新しい朝に戻る。
- **確かめたこと**: 390×844 のヘッドレス Chromium（ソフトウェア描画）で、読み込み・開始時にコンソールエラーなし／お話を最初から最後まで1回通し／各段階で「次の1操作」が光・ゆれ・視線・お手本の指で示されること／WebGL なしで埋め込み画像に切り替わること。
- **未確認・既知の問題**:
  - 音は耳で確かめていない（すべて Web Audio の合成音。笑い声はオカリナ風の音で代用）。
  - 実機（iPhone / iPad の Safari）のタッチ感と実フレームレートは未確認。重いときは解像度を自動で下げ、それでも重いと省電力表示（鏡の解像度・影・髪の本数を減らす）に切り替わる。
  - 髪は毛先がややくし状に見える角度がある。両わきの鏡には女の子は映らない（静止した映り込み）。
  - 掛けたポシェットのひもが体から少し浮く／めり込むことがある。縦長の画面では壁の余白が広め。
  - 保存は localStorage（`gf-261119-1`）。拒否・破損時は保存なしで最初から遊べる。
