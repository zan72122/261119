# ういーん！パパのおたんじょうびケーキ（gf-261119-nx3）

- **起動**: `index.html` をそのまま開く（`file://` でも Pages のサブフォルダでも可）。1ファイル完結・外部読み込みなし。絵も音もすべて実行時に手続き生成（外部素材・外部AIなし）。
- **お話**: 台所のカウンターで、そそぐ → ういーんと泡立てる → のせる → ぬる → いちご → ろうそく → 火をつけるたびに部屋が暗くなり、パパが入ってくる → ケーキを押して渡す → ふーっ（鼻にクリーム）→ クラッカーのひもを引く → 写真が写真立てに入り、次の日もそこにある。
- **作り直すとき**: `npm i` → `node build.mjs`（`src/*.js` と three.js を `index.html` に埋め込む。実行時ビルドは不要）。
- **確かめたこと**: 390×844 で、読み込み・開始時にコンソールエラーなし。ポインター操作で最初から「次の日」まで1回通して遊び、各段階で次の行動が画面内の手がかり（光のたまり・光の点の道・ゆれ・きらり・放置時の半透明の指）で示されることを画面で確認。
- **既知の課題**:
  - 音（Web Audio 合成）は耳で確認していない。実機の iPhone / iPad でも未確認（動作・fps・Safe Area）。
  - パパは「ぼかした背景の人物」として成立させている簡素な3D人形。ぼけを外すと人形に見える。
  - クリームをぬる段階は8秒ほどこすると終わり、やや早い。泡立て中のクリームは真上から見ると後半まで平らに見える。
  - 泡立て中のはねは、ボウルやケーキの上に落ちた分は残さず消している（あとで動く物の上で浮くため）。
  - 確認はヘッドレス Chromium（ソフトウェア描画）のみ。通しプレイは同じソースに確認用の入口を付けた版で行い、製品の `index.html` は読み込み・開始（そそぐまで）を確認した。
  - クラッカーは台に寝かせてひもを手前に引く形。紙ふぶきは見やすさのため実物より上向きに飛ぶ。
